1. 项目概述 Overview

Glory Wisdom 是一个跨系统的新客户上线项目，核心是通过 Vendor Portal + OMS + WMS + EDI 打通"零售商下单 → 工厂/供应商发货 → 仓库履约 → 回传"的端到端直发链路，覆盖直发零售商（Direct ship to retailer）与直发美仓（Direct ship to facility）两大业务场景。 Glory Wisdom is a cross-system new-customer onboarding. It connects an end-to-end drop-ship chain — Retailer order → Vendor/factory shipment → Warehouse fulfillment → confirmation — through Vendor Portal + OMS + WMS + EDI, covering both "Direct ship to retailer" and "Direct ship to facility" scenarios.

5. 关注点与风险 Watch-points & Risks

增量 DC / Partial shipped 等新场景仍在开发/待测（如生产 DN-1995 未发增量 DC），需在客户实际发货前完成验证。 New scenarios like incremental DC / partial-shipped are still in dev/testing (e.g. prod DN-1995 missing incremental DC); need validation before live shipments.
标签与单证高度定制化（UCC / Commercial Invoice / 各零售商差异），需求碎片化、变更频繁，建议固化模板配置化以降低长期维护成本。 Labels/documents are highly customized (UCC / Commercial Invoice / per-retailer variants) with frequent fragmented changes; recommend template-configuration to reduce long-term maintenance.
跨系统链路长（Vendor Portal→OMS→EDI→WMS），存在推单失败/回传中断风险；已建自动重推机制，建议持续监控 DI flow 的 cron 与告警。 Long cross-system chain (Vendor Portal→OMS→EDI→WMS) carries push-failure/return-interruption risk; auto-retry is in place — recommend continuous monitoring of DI-flow crons and alerts.
