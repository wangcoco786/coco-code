1. 项目概述 Overview

Starmerx（星商）是一个以 Item WMS 3.0 为核心的跨境电商小包裹（Small Parcel）履约项目，覆盖收货上架、拣货（Wave Pick）、Parcel Pack & Load 交运、面单/箱唛/ASIN/FNSKU 多标签打印，以及 FBA 调拨出库等电商特有流程。项目已从单仓扩展到多国多站点（美国 TX / NJ、加拿大 Ontario、波兰 Poland 等）。 Starmerx is a cross-border e-commerce Small-Parcel fulfillment project built on Item WMS 3.0, covering receiving/putaway, wave picking, Parcel Pack & Load handover, multi-label printing (shipping label / carton label / ASIN / FNSKU), and FBA transfer outbound. It has expanded from a single site to multiple countries/sites (US TX/NJ, Canada Ontario, Poland).

5. 关注点与风险 Watch-points & Risks

性能压力：曾出现每日 20:00–21:00 系统卡顿、波兰仓中午卡顿、Socket hang up 等问题；随站点与订单量增长需持续容量与性能监控。 Performance pressure: daily 20:00–21:00 slowness, Poland midday slowness, socket hang-ups observed; needs continuous capacity/performance monitoring as sites & volume grow.
预打印面单 / Parcel Load 复杂度高：面单顺序、WAVE_PICK_BY_ITEM 拆包、批量中断补打等仍有活跃缺陷，直接影响发货，需优先保障。 Preprint label / Parcel Load complexity: label sequencing, WAVE_PICK_BY_ITEM splitting, batch-interruption reprint still have active defects that directly impact shipping — high priority.
多站点 / 多租户一致性：facility 未配置、多租户串租户、租户权限等问题反复出现，随扩张需固化站点上线 checklist 与隔离校验。 Multi-site/tenant consistency: unconfigured facilities, cross-tenant leakage, tenant permissions recur — standardize a site-onboarding checklist and isolation checks as it scales.
